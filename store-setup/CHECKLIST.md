# Setup checklist

`YOU` = you must do it (identity, money, passwords, legal acceptance).
`CLAUDE` = can be done for you in the in-app browser.

## 0. Before starting
- [ ] YOU: Send the store name, colours (hex codes), logo and product list from the preview
- [ ] YOU: Have ready: email, phone, Maltese address, ID/passport, IBAN, card for billing
- [ ] YOU: Decide on a business setup (sole trader / company). Shopify Payments asks for it.
      Malta VAT registration is required once you trade; ask an accountant which article (10 or 11).

## 1. Create the store (shopify.com → Start free trial)
- [ ] CLAUDE: Fill in the signup questions (selling online, dropshipping, Malta)
- [ ] YOU: Email + password, verify email
- [ ] CLAUDE: Settings → General: enter values from `store-settings.md`
- [ ] YOU: Settings → Plan → choose **Basic**, enter card

## 2. Theme
- [ ] CLAUDE: Online Store → Themes → add a free theme (Dawn, or similar to the preview)
- [ ] CLAUDE: Customize → Theme settings → Colors: set the colours from the preview
- [ ] CLAUDE: Upload logo, set fonts, build homepage (banner, featured collection, FAQ)
- [ ] CLAUDE: Navigation: main menu (Home, Shop, About, Contact), footer menu (policies)
- [ ] CLAUDE: Create pages: About, Contact, FAQ, Shipping info

## 3. Payments (Settings → Payments)
- [ ] CLAUDE: Open Shopify Payments setup. If Malta isn't offered, use PayPal / Stripe instead
- [ ] YOU: Business details, ID upload, IBAN, 2-step verification
- [ ] CLAUDE: Turn on PayPal Express as a second method (you sign in to PayPal)

## 4. Shipping, taxes, checkout, policies
- [ ] CLAUDE: Settings → Shipping and delivery: zones and rates from `store-settings.md`
- [ ] CLAUDE: Settings → Taxes and duties: prices include VAT, Malta 18%
- [ ] CLAUDE: Settings → Checkout: options from `store-settings.md`
- [ ] CLAUDE: Settings → Policies: paste from `policies/` (after you review them)
- [ ] CLAUDE: Settings → Customer privacy: turn on cookie banner (EU)

## 5. DSers (apps.shopify.com → search "DSers")
- [ ] YOU: Click Install and approve the permissions
- [ ] YOU: Link your AliExpress account inside DSers (sign in to AliExpress)
- [ ] CLAUDE: Apply settings from `dsers-settings.md`
- [ ] CLAUDE: Find suppliers for each product (rating ≥ 4.6, 1000+ orders, EU shipping), import, edit titles/descriptions/images, push to store

## 6. Before launch
- [ ] CLAUDE: Place a test order (Settings → Payments → test mode, or Bogus Gateway)
- [ ] CLAUDE: Check every page on mobile, fix broken links
- [ ] YOU: Remove store password (Online Store → Preferences) when ready
