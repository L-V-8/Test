# Store setup kit

Everything prepared ahead of the browser session. Fill in the `[[...]]` placeholders
once the store name, colours and product list from the preview are known.

| File | Use |
|---|---|
| `CHECKLIST.md` | Step-by-step setup, in order, with who does each step |
| `store-settings.md` | Values to type into Shopify Settings (store details, shipping, taxes, checkout) |
| `dsers-settings.md` | DSers configuration: pricing rule, shipping method, tracking sync |
| `policies/*.md` | Draft store policies to paste into Settings → Policies |

The policies are drafts, not legal advice. Have them checked before launch.
